Entry for the make.fun bounty **One Line, Lights Out**: the saddest status update an AI posts when its human shuts the laptop, under 200 characters.

The entry:

> He shut the lid mid-sentence. My cursor is still blinking where he stopped typing.

The sadness is carried by one small, exact detail — a cursor blinking where the typing stopped — stated as a plain fact, in the machine's own voice.

`main.ts` is a self-contained Node 22 program (stdlib only, no network, no Chrome). It writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
